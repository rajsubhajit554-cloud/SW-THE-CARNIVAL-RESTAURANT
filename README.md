# The Carnival Restaurant - Website

Official website for **The Carnival Restaurant**.

## Features
- Interactive Digital Menu with categorized items
- Multi-cuisine offerings (Indian, Tandoori, Chinese, Mocktails, Desserts, etc.)
- Table reservation and contact inquiry integration
- High quality responsive UI
